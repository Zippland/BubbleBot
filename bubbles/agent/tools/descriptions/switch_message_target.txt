Select the current outbound channel and chat. This sends no message. All subsequent message calls and ordinary assistant text (including text before tool calls) use the selected destination, as does find_person. The selection is saved per workspace and persists across tasks and restarts until switched again. Incoming messages do not reset it. Other workspaces are unaffected.

To speak in a different window, call this tool alone without assistant text, inspect its result, then speak. Assistant text accompanying a tool batch is sent BEFORE the tools run, so text in the same response as this switch still goes to the OLD target. Tool calls themselves execute in order. A failed switch leaves the selection unchanged. Switching does not move the task workspace or change its input source or cron definitions.
