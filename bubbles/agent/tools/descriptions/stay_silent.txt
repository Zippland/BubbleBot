End the current turn (end_turn). The legacy name stay_silent means this tool sends no additional message; it does NOT mean you must have stayed silent throughout the turn.

Call with no arguments when this turn is finished, whether you have already sent replies or have decided no reply is appropriate. A silent turn has neither assistant text nor message calls. Ending does not reset the selected message destination.

Both message and ordinary assistant text are delivered to the selected destination. Text accompanying this tool is still sent; omit text to end without speaking. Prefer calling this after you have inspected the results of your other tools. If included in a batch, all other calls in that batch finish before this ends the turn. It does not undo earlier messages or side effects, and it does not claim that the user's whole task succeeded.
